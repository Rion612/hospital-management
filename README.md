# Hospital Management

A Hospital Management application built with [Node.js](https://nodejs.org/).

## Description

This project aims to manage everyday hospital operations such as patients, doctors, appointments and billing. It is in its early stages; features will be added over time.

## Prerequisites

- [Node.js](https://nodejs.org/) (LTS version recommended)
- npm (comes with Node.js)
- [Git](https://git-scm.com/)

Check your installed versions:

```bash
node -v
npm -v
```

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Rion612/hospital-management.git
   cd hospital-management
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the application:

   ```bash
   node index.js
   ```
